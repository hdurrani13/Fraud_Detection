# Data

Download `creditcard.csv` from [Kaggle: Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) and put it in this folder.

It isn't committed because it's 150 MB (over GitHub's file limit).

Source: Andrea Dal Pozzolo et al., ULB Machine Learning Group. Licensed under [ODbL](https://opendatacommons.org/licenses/odbl/1-0/).
